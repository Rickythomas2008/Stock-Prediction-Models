# 项目关闭总结（S6 closeout）· 2026-11-05

## 1. 关闭原因与判定

**终止条件：QMT 存在资金门槛，当前 10 万元规模不满足，合规自动执行路径不可达。**

这不是「暂时做不了」，而是**目标本身在当前约束下不可达**：

| 链条环节 | 状态 | 是否阻塞终局 |
|---|---|---|
| 数据（akshare / baostock / 自算复权） | ✅ 可用、双源已验证 | 否 |
| 决策链（alpha → 组合 → 风控 → 委托单） | ✅ 可用，R1/R2 路线成立 | 否 |
| 纸面撮合 + 对账 + 审计链 | ✅ 可用 | 否 |
| QMT 极简版（miniQMT）权限 | ❌ **资金门槛未达** | **是** |
| 券商书面确认 + 程序化报告 | ⏸ 未提交（前置条件已不成立） | 是（连带失效） |

按 CSRC〔2024〕8 号「先报告后交易」，无 miniQMT 权限即无合规下单通道；R1（人工照单下单）/R2（条件单）虽仍可运行，但**它们不构成「量化交易系统」的目标形态**——人工照单与手工交易的差别只剩生成 CSV。因此按项目关闭处理，不做降级续命。

保留价值：R1/R2 路线与全部数据、评估、风控资产**完整可用**，资金规模达标后可原地重启，见 §6。

## 4. 结论：哪些假设被证伪（比"做完了"更值钱）

| # | 曾抱有的假设 | 证据 | 结论 |
|---|---|---|---|
| H1 | 「接上真实数据就能知道策略好不好」 | 真实数据上三个 α 全部跑通，但全部 2/3 正超额 | ❌ 链路可用 ≠ 策略有效 |
| H2 | 「换个因子就能跑赢指数」 | momentum/reversal/low_vol 在涨市块**全部跑输**、跌市块全部少亏 | ❌ 问题在结构（低 beta 多头），不在因子 |
| H3 | 「跑赢等权 20 只就算有 α」 | 换基准后：对等权 +1.45pp 是区间构成，对指数才是真基准 | ❌ 基准选错会让结论反向 |
| H4 | 「把资金曲线做成连续就能反映真实账户」 | 重置协议 +2.93% vs 连续 +28.27%，换手从 689% 降到 381% | ✅ 成立，且暴露旧口径系统性低估成本 |
| H5 | 「换数据源不影响结论」 | 同配置同区间差 **4.9pp**；前复权差异最大 0.50% | ❌ 必须设一致性门 + 自算复权 |
| H6 | 「自建池按指数权重 ≈ 指数」 | 前 30 大权重池 3 年 +80.8% vs 指数 +12.9%（两只成分涨 7.6/10 倍） | ❌ 池代理误差 69pp，不是指数 |
| H7 | 「指数增强只要调 tilt 就能加超额」 | 同 alpha=0.4：`tilt=0` +24.99% → `tilt=0.5` +17.65% | ❌ 倾斜在这份数据上是负贡献 |
| H8 | 「装上 xtquant 就能连」 | `PRESENT-BUT-NO-CLIENT`；且 QMT 有资金门槛 | ❌ 技术上与商业上都不可达 |

## 5. 复用资产（脱离本项目仍然成立的经验）

1. **评估协议四件套**：连续资金记账 / 配置也走 walk-forward / 基准必须是可交易标的 / 每个比较都要有恒等式自检行。
2. **三处"假结果"模式**（都真实发生过，且都会在别处重演）：
   - 基准曲线恒 0.00%（索引类型不匹配 → 全 NaN 静默填 0）
   - `tilt=0` 复现不了自己的基准（基准用了理论权重、策略走了撮合层）
   - 留强带 `top_n+buffer ≥ 标的数` → 组合冻结，等于买入持有（已加硬门抛错）
3. **退出码即结论**：一致性门 `0/1/2`（2 = 未执行 ≠ 通过）、探针 `0/1/2`。把"没跑"和"失败"分开，是防止把未验证当通过的最省事手段。
4. **口径先于分析**：volume 单位、复权口径、基准定义——三者任一含糊，后面所有数字都不可复现。

## 6. 重启条件（触发任一条即重启，无需重新设计）

| 触发 | 需要的动作 |
|---|---|
| 资金规模达到券商 miniQMT 门槛 | `tools/xtquant_probe.py` 退出码变 0 → 接 `xtdata` 作第三数据源 → 走 `BROKER-INQUIRY.md` 取书面答复 → R3 模拟盘 |
| 券商明确提供无门槛模拟盘 | 同上，但只到 R3，不涉及资金 |
| 目标改为"低成本指数替代"而非"超额收益" | 直接用当前 `index_enhance.py`，取 `alpha=0.2/tilt=0`（超额全来自池，需换更中性的池） |
| 数据源改为卖方/持牌数据（Wind/iFinD） | 只需实现 `MarketDataProvider` 两个方法，其余全部复用 |

**不要重启的理由**：若目标仍是"用 10 万元跑程序化 A 股"，结论已经明确——不可达，且现有策略在样本外没有可复现 α。
